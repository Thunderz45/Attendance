Biometric Privacy & Data Policy

Information on biometric data handling, security, and storage

1. Purpose of Data Collection

This Face Recognition Biometric Attendance System collects facial data solely for authenticating student identity and automatically logging daily class attendance.

2. Local Vector Embedding Storage

Raw photographs are not permanently stored. When a student registers their face, the system extracts a mathematical feature vector (embedding) of numbers representing face geometry. This vector is stored locally in the college database.

3. Data Security & Third-Party Privacy

  • All processing occurs locally on the campus server/laptop.
  • No facial data or embeddings are transmitted to cloud services or third-party APIs.
  • Admin routes and API endpoints are protected using session-based authentication and password hashing (Werkzeug).
  • SQL database queries use SQLAlchemy ORM to prevent SQL injection vulnerabilities.

4. Right to Deletion & Re-registration

Students or authorized administrators can request complete deletion of biometric embeddings at any time through the Student Directory menu. Re-registering face data overwrites all prior mathematical embeddings.
